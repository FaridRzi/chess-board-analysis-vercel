# Opening names

`openings.json` is generated by `node scripts/build-openings.mjs` from
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) (CC0 public domain).

- `openings`: one `[ECO code, name, moves]` entry per named opening, with the moves as plain SAN
  separated by spaces (no move numbers), spelled exactly as chess.js writes them.
- `keys`: a fingerprint of the position after each move in the opening tree, so the app can recognize
  book positions by position (whatever the move order) without replaying the book in the browser.
- `start`: the fingerprint of the starting position.
